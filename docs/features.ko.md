# 기능

- [o] H1 — P1: plugin이 manifest를 선언하고 `agents.makers`에 harness group을 기여한다. 입력: 저장소에 manifest가 없었다. 기대: `plugin.json`은 surface와 sections를 선언하지 않고, `dependencies`에 `@soksak/plugin-agents`를 두며, `agents.makers`에 module `maker/group.js`를 기여한다. 이 module은 group `id` `harness`와 프로젝트 폴더 `.harness`를 export한다. `test/manifest-rules.test.mjs`는 잘못된 manifest를 각각 이유와 함께 거부한다. 결과: `make test`가 9개 시험을 통과한다.
- [o] H2 — P1: group은 agents plugin의 `agents.makers` item schema(point version 0.1.0)가 요구하는 문자열 필드 `id`와 `name`을 가지며, 기여 range `^0.1.0`은 그 version을 포함한다. 입력: group에 `name`이 없었고, range `^0.0.1`은 0.1.0을 제외해서 item이 `connected`가 아니었다. 기대: item이 schema와 맞고 range가 point version을 포함한다. 이전 H2의 설치 부분은 H4다. 결과: `make test`가 11개 시험을 통과하며, 각 단언은 변경 전에 실패했다.
- [o] H5 — P1: 기여 range를 `^0.0.1`로 되돌린다. 이 range는 `agents.makers`의 point version 0.0.1을 포함한다. agents plugin은 0.1.0을 0.0.1로 고쳤다. version은 0.0을 유지하기 때문이다. 입력: range가 `^0.1.0`이었다. 기대: range가 `^0.0.1`이다. 결과: `make test`가 11개 시험을 통과하며, range 단언 두 개는 변경 전에 실패했다.
- [~] H4 — P1: `maker/group.js`는 `agents/docs/spec/makers.md`의 group object(`id`, `name`, `plugin`, `clis`, `agents`, `skills`, `variables`, `path`, `folders`, `rules`)를 upstream harness(`revfactory/harness`, Apache-2.0) 값으로 반환하는 함수 `group()`을 export한다. 입력: module이 `.harness`를 담은 `projectFolder`의 object `group`을 export해서 item이 `invalid`였다. 기대: `group()`이 필수 member를 모두 반환한다. `clis`는 `claude`, `agents`는 비어 있고, `skills`는 `skills/harness`와 `skills/evolve`를 나열하며, `folders`는 `.claude/`다. upstream 스킬이 agent 정의를 `.claude/agents/`, 스킬을 `.claude/skills/`, `CLAUDE.md`에 쓰고, Claude Code는 `.harness/`를 읽지 않기 때문이다. 결과: `make test`가 21개 시험을 통과하며, `test/group-shape.test.mjs`의 group 단언 11개가 변경 전에 실패했다. 남은 일: 고정한 upstream release와, 두 스킬 폴더, plugin manifest, LICENSE를 `maker/`에 복사하는 build 단계다. 대기 조건: 이 build 단계이며, 이 항목의 다음 unit이다.
- [ ] H3 — P2: CI와 release workflow가 `make install`, `make test`, `make check`를 실행하고, `make pack`이 release를 쓴다. 대기 조건: agents plugin의 첫 release다. `dependencies`의 `@soksak/plugin-agents`를 registry에서 설치할 수 없고, 이 plugin의 version도 그 release와 함께 정한다.
